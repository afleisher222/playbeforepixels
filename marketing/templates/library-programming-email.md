# Public-library email: youth services and collection (3 touches)

**Audience:** youth-services and children's librarians, and Friends of the Library groups (as funders), at public libraries. Selectors get the "For Selectors" variant at the bottom.
**Gate:** after employment counsel clears group-facing sales. **Hold** Montgomery County, MD's public library system until counsel clears it.
**Timing:** Oct–Dec for winter and spring programming. Jan–Mar for summer reading. Collection pitches work year-round.
**Rules:** never use "1000 Books Before Kindergarten" or any program's trademark. Use "works alongside any read-aloud challenge" instead. Never write "library binding" unless a prebinder actually produces a library-bound edition. Make no health claims.
