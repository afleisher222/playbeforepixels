# Archived: logo v1, "The Return"

This folder is an intact copy of the first final logo kit, taken from `brand/logo/` on September 28, 2026, just before the v2 kit replaced it. Nothing inside it has been changed apart from adding this README.

## Why it was retired

**The founder rejected it on September 28, 2026 because it read as the letter r.** The mark was an open P whose bowl was closed by a ball. At small sizes and at a glance, the open bowl and stem read as a lowercase r instead of a P with a ball.

The replacement is the v2 kit in `brand/logo/`: a round maker's seal with the name around the edge and a spinning top in the middle. It was built from concept C in `brand/logo-concepts-v2/c-badge/`.

## Using this folder

- **Do not use these files** on any product, page or listing. They are kept only as a dated record of the design process, which also supports the founder's authorship record (`legal/protection/creation-records-log.md`).
- `src/build.py` still runs from this folder: it reads its own `src/bric800.ttf` and writes its SVGs into this folder, not into `brand/logo/`.
- `logo-guidelines.html` links its fonts as `../fonts/fonts.css`, a path that only worked from `brand/logo/`. The rendered `logo-guidelines.pdf` is complete. To view the HTML with the right fonts, open a copy from `brand/logo/`.
